# Differential analysis

En esta carpeta se hace el análisis de expresión diferencial del proyecto.

Se comparan las muestras entre condiciones para identificar los genes que
cambian su expresión. Los resultados se usan después en la parte de
Pathway analysis.

## Estructura
- `Data/`: matriz de conteos y tabla de metadatos de las muestras.
- `scripts/`: script del análisis.
- `Results/`: tablas de genes diferenciales y gráficos en `Plots/`.
